## 1. Cómo se realizó el proceso
Se construyó una base de datos limpia a partir de Google Trends para Chile (últimos 5 años) con los términos Pistacho, Nueces y Chocolate dubai en la misma consulta y que esten en la misma categoría. 
Se ordenaron los valores de la escala relativa de 0-100. 100 es el peak del periodo por término
Columna temporal de fecha
rellena vacios con 0
Se quitaron los duplicados por fecha
Se muestra que el chocolate dubai estaba en 0 hasta 2024. 
- Herramientas:
- Python
- Google Colab
- Visual Studio 


## 2. Fuentes de datos utilizadas: 
- Google Trends, búsqueda web, Chile, últimos 5 años, todas las categorías.
